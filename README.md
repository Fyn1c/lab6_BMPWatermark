# BMPWatermark project

## Описание приложение
Приложение накладывает водяной знак на ваше изображение. Вам нужно всего лишь убедится, что водяной знак меньше по длине и ширине, чем изображение и указать приложению путь до вашего файла с исходным изображением, до водяного знака, и до файла куда записать результат. 

### Building project

``` 
cmake -B build
```

```
cmake --build build
```
## Запуск проекта
после билда проекта запустить прилождение из папки проекта командой
```
./build/BMPWatermark {input file path} {mark file path} {output file path}
```
файл марки ОБЯЗАТЕЛЬНО должен быть меньшего размера по ширине и длине чем исходный файл
